
# File Endpoints
Start with : baseUrl + /files/....

## renameFile
Route : /rename/:id
**Method:** PATCH  
**Request Body:**
```json
{
  "name": "string"
}
```
**Response:**
```json
{
  "message": "File renamed successfully",
  "name": "string",
  "id": "uuid"
}
```
