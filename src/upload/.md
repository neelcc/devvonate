# Folder Endpoints

## createFolder
Route : "/"
**Method:** POST  
**Request Body:**
```json
{
  "name": "string",
  "parentId": "uuid (optional)"
}
```
**Response:**
```json
{
  "message": "Folder created successfully",
  "name": "string",
  "id": "uuid",
  "parentId": "uuid | null",
  "userId": "uuid",
  "createdAt": "Date",
  "updatedAt": "Date"
}
```

## renameFolder
Route : /rename/:id
**Method:** PATCH  
**Request Body:**
```json
{
  "name": "string"
}
```
**Response:**
```json
{
  "message": "Folder renamed successfully",
  "name": "string",
  "id": "uuid",
  "parentId": "uuid | null"
}
```

## moveFolder
Route : /move/:id
**Method:** PATCH  
**Request Body:**

```json
{
  "message": "Folder moved successfully",
  "name": "string",
  "id": "uuid",
  "parentId": "uuid | null",

```
